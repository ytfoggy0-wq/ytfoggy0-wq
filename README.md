### 🎫 [TicketDesk](https://github.com/ytfoggy0-wq/ticketdesk-bot)

Телеграм-бот приёма заявок. Клиент оформляет заявку в диалоге и получает её номер,
администратор сразу видит уведомление, меняет статус и отвечает клиенту прямо из
карточки — ответ приходит человеку в чат. Плюс поиск по заявкам, статистика и
выгрузка в Excel. Задеплоен и работает 24/7.

**Живой бот:** [@ticketdesk_ru_bot](https://t.me/ticketdesk_ru_bot)

### 📊 [content-zavod](https://github.com/ytfoggy0-wq/content-zavod)

Инструмент анализа Instagram-конкурентов: собирает Reels, транскрибирует их,
считает, какие ролики выстрелили сильнее обычного — чтобы находить идеи для
переснятия. Карточная витрина с превью, AI-описаниями и фильтрами.

**Живая витрина:** [content-zavod-six.vercel.app](https://content-zavod-six.vercel.app)

### 🦷 [dental-landing](https://github.com/ytfoggy0-wq/dental-landing)

Лендинг вымышленной стоматологической клиники — кейс на дизайн, анимации и

без сборки.

**Живая витрина:** [ytfoggy0-wq.github.io/dental-landing](https://ytfoggy0-wq.github.io/dental-landing/)
